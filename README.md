# Telegram-бот продажи сигны для Вельвет

Бот продаёт сигну. После `/start` никакой оплаты: сначала приветствие — «Это бот для сигн
от Вельвет», потом **ник**, и только затем **реквизиты** (Сбер, **0000 0000 0000 0000**,
Имя Фамилия) и **подтверждение оплаты** (фото чека или текст с номером перевода).

Заявки приходят операторам **@werxlq** и **@Luotx**. При подтверждении оператор отправляет
**фото с подписью** — и подпись, и фото уходят покупателю. Дальше оператор может
**продолжить переписку** кнопкой «✍️ Написать по заявке»: любое его сообщение, фото или файл
доходит покупателю, а ответ покупателя реплаем возвращается оператору.

Есть кнопка **«ℹ️ О боте»**: дата создания, разработчик, для кого сделан.

Посторонние сообщения покупателей операторам **не пересылаются** — только заявки и ответы
на сообщения оператора.

Написано на чистом Python 3.9+ — **без pip, без сторонних библиотек**, только стандартная библиотека.
Работает и на Windows, и на Linux/VPS.

## Быстрый старт (5 минут)

### 1. Создать бота и получить токен

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAEabc...xyz`. Это пароль от бота — никому не показывайте.

### 2. Вписать токен в `.env`

```bash
copy .env.example .env      # Windows
# cp .env.example .env      # Linux/macOS
```

Откройте `.env` и заполните:

```ini
TELEGRAM_BOT_TOKEN=123456789:AAEabc...xyz
BOT_USERNAME=Ve1vetz_bot
ADMIN_USERNAME=werxlq,Luotx
PRICE=                  # можно указать сумму, например 500
```

`ADMIN_USERNAME` — список операторов через запятую: покупателю показывается первый,
заявки получают все.

### 3. Запустить бота

```bash
python bot.py
```

или двойным щелчком по `run.bat` (Windows). `run.bat` сам ищет интерпретатор
(`py`, затем `python`, затем Python из комплекта DeepSeek Harness), проверяет `.env`
и не закрывает окно с ошибкой.

> Если на компьютере нет своего Python, бот всё равно запустится: лаунчер возьмёт
> Python из комплекта DeepSeek Harness. Для повседневной работы лучше поставить
> свой Python 3.9+ — тогда `python bot.py` тоже будет работать.

Проверка настроек без запуска:

```bash
python bot.py --check
```

### 4. Подключить операторов

Каждый оператор из `ADMIN_USERNAME` открывает бота и отправляет `/start`.
Всё — с этого момента все заявки и сообщения приходят им в личку, и любой из них
может подтвердить оплату.

> Пока ни один оператор не нажал `/start`, бот сохраняет заявки, но доставить их некому:
> покупатель увидит предупреждение. Альтернатива — прописать `ADMIN_IDS=<chat_id>` в `.env`
> (свой id можно узнать командой `/id` в боте).

### 5. Проверить

Отправьте боту `/start` с другого аккаунта, пройдите сценарий и убедитесь,
что заявка с чеком пришла оператору, а после «Подтвердить» + фото покупатель получил материал.

## Команды

**Покупатель**

| Команда | Что делает |
|---|---|
| `/start` | Приветствие |
| `/info` | Информация о боте |
| `/pay` | Начать заявку |
| `/status` | Статус последней заявки |
| `/cancel` | Отменить текущую заявку |
| `/help` | Как это работает |

**Оператор (@werxlq, @Luotx — все, кто указан в `ADMIN_USERNAME`)**

| Команда / кнопка | Что делает |
|---|---|
| `/start` | Подключиться как оператор, панель управления |
| `/orders` | Список заявок в ожидании |
| `/stats` | Статистика: всего / в ожидании / ждут фото / выполнено / отклонено |
| `/id` | Свой chat_id |
| `/link` | Ссылка на бота для покупателей |
| ✅ Подтвердить | Бот просит фото с материалом → фото и подпись уходят покупателю |
| ❌ Отклонить | Покупатель получает «заявка отклонена» |
| ✍️ Написать по заявке | Переписка: текст, фото, файл — всё уходит покупателю |
| ✖️ Отмена / `/cancel` | Снять подтверждение или закончить переписку |

> Посторонние сообщения покупателей оператору не приходят — только заявки
> и ответы покупателя реплаем на сообщения оператора.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен от @BotFather. **Обязательно** |
| `BOT_USERNAME` | — | Username бота без `@` — для ссылки покупателям |
| `BOT_INTRO` | `Это бот для сигн от Вельвет.` | Приветствие после `/start` |
| `BOT_CREATED` | — | Дата создания для кнопки «О боте» |
| `BOT_DEVELOPER` | — | Разработчик для «О боте» (без `@`) |
| `BOT_FOR` | — | Для кого бот («О боте») |
| `ADMIN_USERNAME` | `werxlq` | Операторы через запятую (без `@`). Первый — лицо бота в текстах |
| `ADMIN_IDS` | — | chat_id операторов через запятую (альтернатива `/start`) |
| `CARD_NUMBER` | `0000 0000 0000 0000` | Номер карты для оплаты |
| `CARD_HOLDER` | `Имя Фамилия` | Получатель |
| `BANK` | `Сбер` | Банк |
| `PRICE` | — | Сумма; пусто — строка скрыта |
| `PRODUCT` | `сигну` | Что продаём: «Здесь можно купить **сигну**» |
| `TELEGRAM_PROXY` | — | Прокси для `api.telegram.org`, если прямой доступ закрыт |
| `RATE_LIMIT_COUNT` / `RATE_LIMIT_WINDOW` | `20` / `60` | Антиспам: не больше N сообщений за M секунд |

Все тексты сообщений — в `texts.py`, правятся без знания Python-логики.

## Постоянная работа

**Windows (просто, без службы):** запускайте `run.bat`, окно не закрывайте.
Автозапуск — «Планировщик заданий» → задача «При запуске компьютера» → `run.bat`.

**VPS (24/7):** пошаговая инструкция — в [DEPLOY.md](DEPLOY.md): какой сервер купить,
как подключиться, одной командой поставить и включить автозапуск.

Самый короткий путь со своего компьютера:

```powershell
deploy\deploy.bat IP_СЕРВЕРА      # зальёт папку, установит сервис, покажет лог
```

Коротко, если сервер уже есть:

```bash
cd /opt/werxlq-bot
sudo bash deploy/install.sh     # поставит Python, сервис и запустит
journalctl -u werxlq-bot -f     # логи
```

Юнит лежит в `deploy/werxlq-bot.service`, бэкап заявок — `deploy/backup.sh`.

**Docker:**

```bash
docker compose up -d --build
```

Том `./data` сохраняет заявки между перезапусками. **Важно:** один токен — один запущенный
экземпляр. Если запустить бота дважды, Telegram вернёт ошибку `409 Conflict`.

## Безопасность — прочитайте

1. **Токен — это пароль.** `.env` уже в `.gitignore`: не выкладывайте его в чаты и репозитории.
   Если токен утёк — у @BotFather: `/revoke` и новый токен.
2. **`sk-27b5…` из переписки боту не нужен.** Это не токен Telegram, а ключ внешнего API.
   Бот его не использует и нигде не сохраняет — ключ стоит **отозвать** у его владельца,
   раз он уже побывал в чате.
3. **Бот не собирает данные карт покупателей.** Если покупатель присылает номер карты,
   бот предупреждает и не принимает его. CVV/ПИН не запрашиваются никогда.
4. **Оплату подтверждает человек.** Бот не проверяет поступление денег: он передаёт чек
   оператору, а оператор нажимает «Подтвердить». Автоматической сверки со Сбером тут нет
   (и в открытом API Сбера для физлиц её нет) — не выдавайте заявку до подтверждения.
5. **Права оператора.** Операторами становятся владельцы username из `ADMIN_USERNAME`
   (список через запятую) или id из `ADMIN_IDS`. Кнопки подтверждения у посторонних
   не работают (проверяется на сервере).
6. **Бэкап.** `data/state.json` — это вся история заявок. Копируйте его перед переездом.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `409 Conflict` | Бот уже запущен в другом месте (второе окно, сервер). Остановите лишний экземпляр |
| `Telegram не принял токен` (401) | Токен неверный или отозван. Получите новый у @BotFather |
| «Оператор ещё не подключён» | никто из `ADMIN_USERNAME` не нажал `/start`; либо задайте `ADMIN_IDS` |
| Бот молчит, в логе сетевые ошибки | Нет доступа к `api.telegram.org`. Укажите `TELEGRAM_PROXY=http://127.0.0.1:8080` в `.env` или включите VPN |
| `getUpdates: сеть (getaddrinfo failed)` / `Errno 11001` | DNS не смог разрешить `api.telegram.org`: пропал интернет, DNS-сервер недоступен или провайдер блокирует Telegram. Бот сам повторяет попытки — если DNS вернулся, он подключится. Если повторяется: DNS `1.1.1.1`/`8.8.8.8`, VPN или `TELEGRAM_PROXY` |
| `python bot.py` открывает Microsoft Store | В PATH стоит заглушка Python из Store. Запускайте `run.bat` — он отличит заглушку и найдёт настоящий Python |
| Заявка пришла без фото | Telegram не отдал файл; заявка всё равно сохранена, покупатель может прислать чек текстом |
| Нужно поменять тексты | `texts.py`, затем перезапуск |

Диагностика сети (DNS → TCP → HTTPS, по шагам):

```bash
python bot.py --net
```

Показывает, на каком шаге рвётся: не резолвится имя (DNS), не открывается порт 443
(блокировка провайдером) или уже сам API-запрос (токен/прокси).

Проверка настроек:

```bash
python bot.py --check
```

Показывает токен (маскированно), операторов, реквизиты, число заявок и доступность Telegram.
